# Türkçe · PWA

Учебник по турски за българи. Едностраничен PWA — без билд стъпка, без зависимости.

```
index.html              приложението (учебник, четива, диалози, речник, тестове)
manifest.webmanifest    име, икони, цветове, бързи връзки
sw.js                   service worker — офлайн кеш
icons/                  192, 512, maskable 512, apple-touch 180, favicon 64
```

## Пускане на GitHub Pages

```bash
git init
git add .
git commit -m "Türkçe PWA v39"
git branch -M main
git remote add origin https://github.com/Yani81/<repo>.git
git push -u origin main
```

После: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

Адресът става `https://yani81.github.io/<repo>/`. Всички пътища в манифеста и в
service worker-а са относителни (`./`), затова работи и в подпапка — не са
нужни промени.

## Инсталиране на телефона

- **Android/Chrome** — в чекмеджето се появява бутон **⤓ Инсталирай**.
- **iPhone/Safari** — бутонът показва подсказка: меню за споделяне → „Към началния екран“.

След инсталиране приложението се отваря на цял екран, без адресна лента, и
работи изцяло офлайн.

## Ново издание

Service worker-ът кешира черупката по версия. При нова версия:

1. Смени `VERSION` в `sw.js` (напр. `'v40'`).
2. Качи промените.

Старият кеш се изтрива автоматично, а потребителят вижда съобщение
„Има ново издание. Затвори и отвори приложението.“

Без стъпка 1 браузърът може да покаже старата версия от кеша.

## Кеш за снимките

Картинният речник тегли снимки от Wikimedia. Service worker-ът ги кешира при
първо зареждане в отделен кеш (`pics-v1`), който **не** се трие при ново
издание — снимките се теглят веднъж и после работят офлайн.

## Локална проверка

Service worker не работи от `file://`. За тест:

```bash
python3 -m http.server 8000
```

и отвори `http://localhost:8000`. За реален PWA тест на телефон е нужен HTTPS
(GitHub Pages го дава).
